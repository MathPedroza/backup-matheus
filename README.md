Aplicativo de backup desenvolvido em Delphi para Windows.



\## Funcionalidades



\- Backup total, incremental e diferencial

\- Compactação ZIP

\- Inclusão opcional de arquivos ocultos e de sistema

\- Validação de integridade por SHA-256

\- Agendamento de backups

\- Registro detalhado da execução



\## Ambiente de desenvolvimento



\- Delphi 11 Alexandria

\- Plataforma Win32

\- Componentes JVCL

\- Componentes DevExpress VCL

\- Indy/OpenSSL



\## Projeto principal



Abra o arquivo:



`Projeto\\Backup.dproj`



\## Testes



Os testes do motor de backup estão em:
